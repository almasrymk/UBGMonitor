- `DONE-VERIFIED` — نُفذت، والاختبارات التي تثبتها اشتغلت فعلاً في بيئة Codex ونجحت.

- `BLOCKED` — لم تُنفذ. يُذكر المدخل الناقص أو الافتراض الذي فشل.
